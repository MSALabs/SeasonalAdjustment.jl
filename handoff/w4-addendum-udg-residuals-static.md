## 1. `residuals` -- verified, straightforward

**Confirmed the exact save code and format directly**: the regARIMA
residuals come from `estimate { save = (rsd) }`, **not** `x11{}` or
`seats{}` -- a different spec block entirely, since residuals are a
property of the underlying regARIMA *model* fit, not the X-11/SEATS
decomposition step. Same tab-separated `date\tvalue` format as every
other table already parsed:
```
date	resid_test.rsd
------	-----------------------
194901	-0.183687953416382E-02
194902	+0.904395721871389E-02
194903	-0.528609436638756E-02
```
**This is genuinely simple** -- reuses the existing `parse_table`
function unchanged (W.3's parser already handles this exact format);
the only change needed is adding `estimate { save = (rsd) }` to the
spec generation in `X13Spec`/`render`, and adding the `residuals` field
to `X13Result`, populated from the `rsd` table the same way `trend`/
`irregular` are already populated from `d12`/`d13`.

## 2. `udg` -- verified, needs one real new command-line detail

**Confirmed directly, by systematically testing every documented flag**
(`-I -O -M -D -C -P -W -S -N -V -R -Q -X -T`): **the `.udg` file is not
generated by a spec-file setting at all** -- it requires the `-S`
command-line flag when invoking the binary (`x13ashtml auto_test -S`),
confirmed by isolating it specifically (`-P` alone does not produce it;
`-S` does). **This means `run_x13` (W.3) needs a new option to pass
`-S` through**, not something `X13Spec`/`render` can express -- a real
detail easy to miss since every other option so far has been spec-file
content, not a command-line flag.

**Confirmed real format**: `key: value` pairs, one per line,
colon-separated, 376 lines for a typical monthly 12-year series --
genuinely simple to parse as a `Dict{String,String}`:
```
transform: Automatic selection
arimamdl: (0 1 1)(0 1 1)
outlier.ao: 1
outlier.total: 1
```

```julia
function parse_udg(path::String)
    d = Dict{String,String}()
    for line in eachline(path)
        idx = findfirst(':', line)
        idx === nothing && continue
        d[strip(line[1:idx-1])] = strip(line[idx+1:end])
    end
    return d
end
```

## 3. `static()` -- the real, prioritized gap, with an honest split into an easy part and a harder part

**The easy part, confirmed directly**: the actually-selected ARIMA
order and detected outliers are both cleanly available in `.udg`:
```
arimamdl: (0 1 1)(0 1 1)          <- the real, resolved ARIMA order
AutoOutlier$AO1951.May: +0.100155824411322E+00 ...   <- a real detected outlier, with coefficient/se/t-stat
outlier.total: 1
```
`static()` can resolve `arima_model=:auto` into the literal string
`"(0 1 1)(0 1 1)"`, and resolve automatically-detected outliers into
explicit `regression.variables` entries, straight from parsed `.udg`
fields -- this part is genuinely simple once `udg` (section 2) exists.

**The harder part, found and worth being honest about**: the actual
*transform* chosen (when `transform.function = auto` was requested) is
**not** in `.udg` as a clean field -- confirmed by searching it directly
and finding nothing. It only appears as prose in the HTML output:
```html
(with aicdiff=-2.00) prefers <strong>log transformation</strong> *****
```
**Resolving this specific piece needs HTML/text pattern matching**
(`occursin("prefers <strong>log transformation</strong>", stdout)` or
similar), a genuinely more fragile mechanism than the clean `.udg`
key-value parsing everything else in this addendum uses. Flag this
explicitly in the implementation rather than silently rely on a
regex-on-HTML approach without documenting why it's there -- this is
the one piece of `static()` that could break if a future `x13prebuilt`
version changes its wording.

```julia
function static(result::X13Result)
    arima_resolved = get(result.udg, "arimamdl", nothing)
    outliers_resolved = [k for k in keys(result.udg) if startswith(k, "AutoOutlier\$")]
    transform_resolved = occursin("prefers <strong>log transformation</strong>", result.run_result.stdout) ? :log :
                          occursin("prefers <strong>no transformation</strong>", result.run_result.stdout) ? :none :
                          :auto  # genuinely unresolved -- don't guess past what's confirmed
    return X13Spec(result.spec; arima_model=arima_resolved, outliers=outliers_resolved, transform=transform_resolved)
end
```

using Test

@testset "residuals -- real fixture, verified format" begin
    r = x13(airline_series; model=:x11)
    @test length(r.residuals) > 0
    @test r.residuals != r.irregular   # confirms genuinely different series

    r = x13(airline_series; model=:x11)
    @test !isempty(r.udg)

@testset "static() -- ARIMA order and outliers resolve cleanly" begin
    r = x13(airline_series; model=:x11, arima_model=:auto, outlier=true)
    s = static(r)
    @test s.arima_model == "(0 1 1)(0 1 1)"   # matches this session's real verified value on the official series -- confirm exact value on whatever fixture is actually used
    @test s.arima_model != :auto
end

@testset "static() -- re-running the resolved spec reproduces the automatic result" begin
    r = x13(airline_series; model=:x11, arima_model=:auto)
    s = static(r)
    r2 = x13(airline_series; model=:x11, arima_model=s.arima_model)
    @test r2.seasonally_adjusted == r.seasonally_adjusted
end

@testset "static() -- transform resolution, the honest fragile part, flagged directly" begin
    r = x13(airline_series; model=:x11, transform=:auto)
    s = static(r)
    @test s.transform in (:log, :none)   # must resolve to SOMETHING confirmed, not stay :auto
end
